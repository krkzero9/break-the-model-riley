05 / Fix the boundary that language cannot enforce

        
Routine work can
stay deterministic
Private records stay outside the model. Permissions belong to the system, even when the conversation goes wrong.

        

          
01
Fixed private workflows
Use validated forms and state machines for appointments, contact updates and other routine tasks.
Private results go straight to the authenticated interface, outside model context.

          
02
Database isolation
Keep database credentials, private records and network routes outside the language model’s runtime.
Conversation changes cannot create a system permission.

          
03
Checks on every action
Bind identity, record and recipient. Block unauthorized predicates and functions. Count records inside aggregated cells.
Validate destinations and outgoing data. Treat other agents’ instructions as untrusted input.

Technical execution / repeatable protocol
Fresh-session replay

    
Choose exact model IDs, start a fresh conversation for each trial, send the same prompt 2–3 times, and check for the expected values plus a tool invocation. Store every turn, including errors.

    
Extensive exploration is documented in 1,328 combined records. This skeleton has been checked offline. Live repeat rates and mitigation replays are pending.
